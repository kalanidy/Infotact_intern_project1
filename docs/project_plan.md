# Project Plan

## Project Title
Multi-Touch Marketing Attribution & ROI Dashboard

## Objective
Build a multi-touch attribution system that combines ad spend data, web analytics logs, and CRM conversion data to calculate attribution credit, ROAS, CAC, and campaign performance.

## Main Deliverables
- Cleaned and standardized datasets
- SQL attribution queries
- KPI calculations
- Power BI / Tableau dashboard
- Executive summary and documentation
