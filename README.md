# Infotact Intern Project 1
## Multi-Touch Marketing Attribution & ROI Dashboard

## Project Overview
This project focuses on building a Multi-Touch Marketing Attribution model for marketing campaign analysis. The goal is to assign conversion credit across multiple touchpoints and evaluate channel performance using metrics such as ROAS and CAC.

## Datasets
The project will use three datasets:
1. Ad Spend Data
2. Web Analytics Logs
3. CRM Conversion Data

## Tools
- Python (Pandas, Matplotlib)
- SQL
- Power BI / Tableau
- GitHub

## Week 1 Focus
- Set up repository structure
- Perform EDA on the three datasets
- Document dataset columns and cleaning steps

## Folder Structure
- `data/raw/` → original raw datasets
- `data/cleaned/` → cleaned datasets
- `notebooks/` → EDA notebooks
- `sql/` → SQL scripts
- `docs/` → project documentation
- `dashboard/` → dashboard planning notes
